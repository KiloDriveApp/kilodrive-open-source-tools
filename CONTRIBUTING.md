# Contributing

1. Create a focused branch.
2. Add or update tests for behavioral changes.
3. Run `python -m unittest discover -s tests -v`.
4. Run `python -m compileall -q src tests`.
5. Verify that examples contain only synthetic data.
6. Do not commit credentials, private screenshots, production URLs, personal data, or proprietary schemas.

Bug reports should include the tool version, operating system, command, sanitized configuration, expected behavior, and actual behavior.
